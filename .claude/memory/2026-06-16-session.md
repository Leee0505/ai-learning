## 2026-06-16 Session Summary

### Bugs Fixed
- **MyBatis-Plus pagination not working**: Missing `PaginationInnerInterceptor` → SQL no LIMIT, 3s queries
- **Send Reply button stuck disabled**: Vditor instance not reactive → added `input` callback → `replyContent` ref bridge
- **Dashboard nav always highlighted**: Vue Router 4 `exact` prop not supported → switched to manual `:class` binding with `$route.path.startsWith()`
- **Vditor toolbar icons missing/ugly**: `stroke-width` override broke SVGs, wrong toolbar item names (`hr`→`line`, `image`→`upload`), `overflow:hidden` clipped tooltips
- **Error messages swallowed**: `try-catch` wrapped ElMessageBox + API together → separated into two try-catch blocks across all views
- **Template/Knowledge save shows generic error**: `catch {}` → `catch(e) { ElMessage.error(e.response?.data?.message) }`

### Features Implemented

#### Editor
- Vditor WYSIWYG mode replaces textarea in reply + create ticket
- Toolbar: bold, italic, quote, list, ordered-list, code, link, upload, table, line, undo, redo
- Image upload in reply → auto-creates attachment via API
- `strikethrough` and `underline` NOT supported by Vditor WYSIWYG (known limitation)

#### Reply System
- Edit/delete own replies (V6 migration: `is_edited` flag)
- `PUT /tickets/{id}/replies/{replyId}`, `DELETE /tickets/{id}/replies/{replyId}`
- Relative timestamps (dayjs relativeTime): "2 hours ago", "yesterday"
- "edited" badge on modified replies

#### Workbench
- Optimistic UI update for ticket claim (instant move, no 2x API refresh)
- In-flight state per ticket (takingIds Set) → button disabled during claim

#### Templates
- V7 migration: `reply_template` table + 5 seed templates
- CRUD API at `/api/templates`, management page at `/templates`
- "Templates" dropdown button in reply editor → click to insert
- Duplicate title validation

#### Knowledge Base

- "Knowledge" button in reply editor with search popover → click to insert

#### Profile

#### Performance Dashboard
